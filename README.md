# Blaze Main App V2

1. Copy your existing `.env` into this folder.
2. Run `npm install`.
3. Run `npm run dev`.

The create wizard includes a local prompt enhancer and structured website generator. For true model-generated output, enable Firebase AI Logic later and connect it in `src/firebase.js`.

Place the final purple logo at `public/logo.png` when available and replace the Flame mark in `src/main.jsx` with an image tag.
